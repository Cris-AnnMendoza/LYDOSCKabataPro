ACCREDITATION DOCUMENT TEMPLATES
=================================

Place the following template files in this folder:

1. 1-LYDO-Accreditation-Form.pdf
   - The PDF file from "1- LYDO ORGANIZATION ACCREDITATION FORM"
   
2. 2-Directory-Officers-Advisers.docx
   - Template from "2-Directory-of-Officers-Advisers.docx"
   
3. 3-Members-List.xlsx
   - Template from "3- List-of-Members-in-Good-Standing.xlsx"
   
4. 4-Constitution-Bylaws-Template.docx
   - A blank template for organization constitution and by-laws
   
5. 5-YORP-Registration-Form.docx
   - Template from "1-5 YORP NYC Registration-Form.docx"

These files will be downloadable by organization presidents who want to apply for accreditation.

NOTE: You need to manually copy these files to this directory:
c:\xampp\htdocs\LYDO\lydo-system\org-president\documents\
